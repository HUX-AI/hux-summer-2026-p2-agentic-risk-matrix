### How it was built

Each column of the matrix was researched independently against a shared reference scale, then reconciled at the end of the project. The taxonomy was derived from the agent's own operating workflow and the OWASP mapping applied after the structure was settled. Sixteen scenarios were written to test the ladder across domains.

Eight scenarios were run through the full instrument against the team's own judgement. Seven produced the expected result. The eighth — a GMP biologics case — had treated human review and substantive source verification as equivalent, which in a regulated documentation setting they are not. The required-controls text now demands verified sign-off and names rubber-stamping as the failure the control prevents.

### Why amplifiers sit outside the base rating

A missing approval step does not mean the same thing everywhere. In a summarisation tool it produces an unwanted output; in an ordering API it produces transactions. Execution speed changes the scale of a failure: a person applying a policy wrongly affects the cases they handle, while an agent can apply the same error across a queue before anyone notices.

### Supervision is a capability, not a checkbox

A human approval step counts as a control only where the reviewer has enough visibility into the system and enough authority to challenge the output and stop the action. An approval field a reviewer cannot exercise is a recorded step, not a control.

### Impact is a property of the deployment

The same retrieval assistant is negligible-impact on a canteen menu and critical-impact on a safeguarding pathway. Classify the use case, not the technology.
