Enterprise AI is moving from systems that answer to systems that act. A chatbot that gives a wrong answer and an agent that issues a wrong refund are not the same governance problem, but most organisations control them with the same policy.

This matrix separates two questions that usually get collapsed into one:

**How much can the system do on its own?** That is the autonomy level, L0 through L5.

**How bad is it if the system gets it wrong?** That is the impact class, I0 through I3.

The control posture lives at the intersection. A system at low autonomy and critical impact is not a low-risk system — it is a system whose failure runs through a human instead of through an API call. The matrix is designed to make that visible rather than let it hide behind "it can't actually do anything."
